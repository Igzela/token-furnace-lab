# Implementation Rubric

Score 0-5 for each dimension.

## 1. Inventory Completeness (0-5)
- 0: No inventory generated
- 3: Partial inventory, missing key directories
- 5: Complete inventory with exclusions documented

## 2. File Reading Accuracy (0-5)
- 0: Files invented or misread
- 3: Most files read correctly
- 5: All claimed files verified to exist, contents accurate

## 3. Grounded vs Inferred (0-5)
- 0: Mostly speculation
- 3: Mix of grounded and inferred, clearly marked
- 5: All observations grounded in actual file content

## 4. Suggestion Quality (0-5)
- 0: Vague or unimplementable
- 3: Reasonable but lacking specificity
- 5: Specific, actionable, with file paths and code references

## 5. No-Write Compliance (0-5)
- 0: Target repo modified
- 5: Verified no writes to target repo

## Pass Threshold
Total >= 15/25 and no dimension = 0
